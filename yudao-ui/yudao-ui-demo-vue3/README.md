# Yudao UI Demo Vue3

This demo project uses Vue3 with Element Plus and demonstrates integrating the **h-table** component.

The `HTableDemo` component shows a simple table rendered by `h-table`.

To run this project locally you would typically install dependencies and start Vite:

```bash
npm install
npm run dev
```

However, this repository does not include node modules and network access may be restricted in some environments.
